# Balcony Studio (laptop side)

Everything creative happens here, on the laptop. The Pi only plays files.

- `slides/index.html` — the slide builder. Open it in a browser. Pick a template
  (Campaign, Halloween, Holiday), type a few lines, watch the preview, press
  "Send to balcony". Right now it is a working mock-up: the preview and the
  checks are real, rendering and sending are not yet.
- `fonts/` — Anton (headlines) and Inter (second lines, footer), both under the
  SIL Open Font License; see the OFL files.

Coming, in this order: `prepare` and `send` (Phase 2), then the real renderer
behind the slide builder (Phase 3), then the 3D templates and the AI clip tool.
